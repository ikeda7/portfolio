7# Diretrizes de Desenvolvimento do Portfólio

## 1. Regra de Ouro (Sem Freestyle)

- NENHUM dado de projeto, experiência profissional ou habilidade deve ser inventado ou preenchido com dados genéricos.
- Todo o conteúdo de texto deve ser estritamente mapeado do meu currículo (que será fornecido) e do meu GitHub.
- Se faltar informação para preencher um componente de UI, use placeholders visíveis (ex: [INSERIR LINK AQUI]) e me pergunte no terminal.

## 2. Stack Tecnológica

- React + TypeScript (Vite).
- Estilização estrita com Tailwind CSS.
- Animações complexas devem ser feitas preferencialmente com Tailwind (transitions/hover) e, quando necessário, Framer Motion ou GSAP.

## 3. Arquitetura e Componentização

- Separe os blocos da landing page em componentes isolados (ex: `Hero.tsx`, `About.tsx`, `Skills.tsx`, `Projects.tsx`).
- Mantenha o código limpo, modular e tipado corretamente no TypeScript.
- O tema do site é "Dark Studio" (mix de estúdio de áudio com interface de IA e Dados). Mantenha a paleta de cores (Fundo carvão, detalhes em Roxo Neon).
